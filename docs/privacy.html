Remote

개인정보처리방침

시행일: 2026년 9월 29일

이 방침은 Remote의 PC 호스트(Windows·리눅스)와 안드로이드 앱(이하 "Remote")이 어떤 정보를 어디에서 처리하는지 설명합니다. Remote는 개인 개발자 BlackBuddle이 만들어 배포합니다.

  • 개발자는 서버를 운영하지 않으며, 사용자의 계정·화면·입력 정보를 받지 않습니다.
  • 로그인과 PC 목록은 사용자가 직접 만든 Firebase 프로젝트에 저장됩니다.
  • PC 화면과 입력은 저장되지 않고, PC와 폰이 암호화된 연결로 직접 주고받습니다.
  • 안드로이드 앱은 Google AdMob 광고를 보여 주며, Google이 광고를 위해 광고 ID 등을 수집할 수 있습니다.

함께 쓰는 외부 서비스

  • Google Firebase·Google 로그인 — 사용자 본인의 Firebase 프로젝트에서 동작하며, 그 데이터에는 사용자가 동의한 Google·Firebase 약관이 적용됩니다. 개발자는 사용자의 Firebase 프로젝트에 접근할 수 없습니다. Firebase 개인정보 보호
  • Google STUN 서버(stun.l.google.com) — PC와 폰이 직접 연결할 주소를 찾을 때 각 기기의 공인 IP 주소를 확인하는 데 씁니다.
  • GitHub — 설치된 Windows 호스트가 새 버전을 확인하고 내려받을 때 GitHub에 접속합니다. 이때 GitHub가 PC의 IP 주소를 받을 수 있습니다.
  • Google AdMob(안드로이드 앱) — 원격 화면 위쪽에 배너 광고를 보여 줍니다. Google은 광고를 보여 주고 측정하며 부정 사용을 막기 위해 광고 ID, IP 주소, 기기·앱 정보, 광고를 보거나 누른 기록을 수집할 수 있습니다. 자세한 내용은 Google 파트너 사이트·앱의 정보 사용 방식에 있습니다. 광고 ID는 안드로이드 설정의 Google → 광고(기기에 따라 개인정보 보호 → 광고)에서 재설정하거나 삭제할 수 있습니다.

개발자가 받는 정보

개발자는 사용자를 알아볼 수 있는 정보를 받지 않습니다. AdMob에서 광고 노출 수·수익 같은 집계된 통계만 볼 수 있습니다.

보관과 삭제

  • Firebase 프로젝트의 데이터는 사용자가 Firebase 콘솔에서 직접 지우거나 프로젝트를 삭제할 수 있습니다.
  • 앱을 삭제하면 폰에 저장된 설정·로그인 정보·사용량이 함께 지워집니다.
  • PC의 설정·로그인 정보·로그는 사용자 폴더의 .remotehost 폴더를 지우면 없어집니다.
  • 구글 계정에서 Remote의 접근을 끊으려면 구글 계정의 타사 연결에서 삭제하세요.

아동

Remote는 13세 미만 어린이를 대상으로 하지 않습니다.

English summary

Remote (the PC host and the Android app) is made by an individual developer, BlackBuddle, who runs no servers and receives no account, screen or input data. Sign-in and the PC list live in the Firebase project that each user creates. Screen and input travel only over an encrypted peer-to-peer WebRTC connection and are not stored. Google's STUN server sees device IP addresses when connections are set up, and the Windows host contacts GitHub to check for updates. The Android app shows Google AdMob banner ads; Google may collect the advertising ID, IP address, device and app information and ad interactions (see How Google uses information from sites or apps that use our services). The developer sees only aggregated AdMob statistics. Remote is not directed at children under 13. Contact: GitHub Issues.
