Remote
할 수 있는 것 시작하기 쓰는 법 안전 다운로드

폰에서 내 PC를 보고, 그대로 조작합니다

PC에 호스트를, 폰에 Remote 앱을 설치하면 같은 구글 계정의 PC가 목록에 뜹니다. 누르면 1초 남짓 만에 연결되고, PC 화면을 보며 마우스와 키보드로 다룹니다.

Windows 호스트 받기 .msi 안드로이드 앱 받기 .apk

지금 버전 1.0.6. 무료이고, 내 Firebase 프로젝트로 동작합니다.

할 수 있는 것

사람이 PC 앞에 없어도 계속 쓸 수 있게 만들었습니다. 연결이 끊기면 다시 붙고, 폰에서 PC를 재시작하거나 업데이트할 수도 있습니다.

보고 조작하기

  • 🖥
    PC 화면을 원래 해상도로최대 3840×2160, 초당 30장. 두 손가락으로 확대하고 옮깁니다.
  • 👆
    끌면 커서 이동, 누르면 클릭좌·중·우 클릭과 드래그 고정을 지원합니다.
  • ⌨
    가상 키보드와 한/영 키씽크패드 배열과 트랙포인트. 블루투스·USB 키보드도 그대로 전달됩니다.

연결

  • 🔌
    계정으로 찾는 PC 목록IP 입력도 짝짓기도 없이, 켜진 PC를 누르면 연결됩니다.
  • ↻
    끊기면 다시 연결방금 쓰던 그 PC로 자동으로 다시 붙습니다.
  • 📊
    사용량 그래프Firebase 무료 한도 대비 사용량을 폰과 PC에서 봅니다.

PC 관리

  • 🔄
    폰에서 PC 재시작다시 켜지면 저절로 연결합니다. PC에서 허용한 경우에만.
  • 🔓
    WinLocker 잠금 풀기·다시 잠그기WinLocker를 쓰는 PC에서, PC가 허용한 경우에만.
  • ⬆
    자동 업데이트새 버전을 미리 받아 두고, 버튼 한 번으로 설치합니다.

어떻게 연결되나요

  • 화면과 마우스·키보드 입력은 PC와 폰이 직접(P2P) 주고받습니다. 중간에 거치는 서버가 없습니다.
  • 연결을 시작할 때의 짧은 신호와 기기 목록만 내가 만든 Firebase 프로젝트에 저장되고, 내 계정만 읽고 쓸 수 있습니다.
  • 개발자가 운영하는 서버나 계정은 없습니다. Firebase 무료 요금제로 충분합니다.

시작하기

처음 한 번만 설정하면 됩니다. 자세한 순서와 화면 위치는 README의 처음 설정에 있습니다.

  1. 내 Firebase 프로젝트 만들기

    구글 로그인과 Realtime Database를 켜고, 안드로이드 앱과 그 지문을 등록합니다. 10~20분쯤 걸립니다.

  2. PC에 호스트 설치

    .msi를 실행합니다. "Windows의 PC 보호" 창이 뜨면 추가 정보를 누른 뒤 실행을 누르세요.

  3. 폰에 앱 설치

    .apk를 열고, 처음이면 출처를 알 수 없는 앱 설치를 허용합니다.

  4. 설정값 넣고 로그인

    호스트와 앱에 같은 프로젝트의 값을 넣고, 같은 구글 계정으로 로그인합니다.

  5. 연결

    앱의 ⚙ 메뉴에서 🔌 연결을 누르고, 초록 점이 붙은 PC를 고릅니다.

쓰는 법

폰 앱 오른쪽 위의 ⚙를 누르면 메뉴가 열립니다. 쓸 수 없는 버튼은 바로 아래에 이유가 나옵니다.

🔌연결

같은 계정의 PC 목록을 열어 연결합니다.

🔄재시작

연결된 PC를 재시작합니다.30초 카운트다운 동안 취소할 수 있습니다.

⚙Firebase

앱의 Firebase 설정값을 고칩니다.

🔓잠금 해제

WinLocker 잠금을 풉니다.🔒 PC 잠금으로 다시 잠급니다.

📊사용량

이 폰의 Firebase 사용량을 봅니다.

⬆업데이트

호스트가 새 버전을 받아 두었을 때 나타납니다.누르면 1분쯤 뒤 새 버전으로 다시 연결됩니다.

PC 호스트에서

  • 창을 닫아도 트레이에서 계속 동작합니다. 완전히 끄려면 트레이 아이콘을 오른쪽 클릭해 종료를 누르세요.
  • ⚙ 메뉴에서 자동 로그인과 PC 시작 시 자동 실행을 켤 수 있습니다.
  • 폰에서의 PC 재시작과 WinLocker 잠금 해제는 기본으로 꺼져 있고, PC 앞에서 직접 허용해야 합니다.
  • 재시작 뒤 폰이 다시 붙으려면 PC 시작 시 자동 실행과 Windows 자동 로그인이 필요합니다.

안전하게

  • 폰이 연결되면 PC에 알림이 뜹니다. 내가 한 연결이 아니면 트레이에서 종료하세요.
  • PC의 자동 로그인 정보는 그 PC의 그 Windows 사용자만 풀 수 있게 암호화해 저장합니다.
  • PC를 잃어버렸다면 구글 계정의 타사 연결에서 호스트의 접근을 삭제하세요.

알아 둘 점

  • Windows 11과 Android 7.0 이상에서 확인했습니다.
  • 중계 서버를 쓰지 않아서, 기기끼리 직접 연결을 막는 일부 회사·학교 망에서는 연결되지 않을 수 있습니다.
  • 일부 기기는 앱을 오래 뒤에 두면 시스템이 앱을 닫아 연결이 끊길 수 있습니다.
